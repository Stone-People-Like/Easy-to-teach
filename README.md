## 项目简介

本仓库用于承载中等职业教育技能教材（精简版）相关教学资料，目标是用更精简、直观的形式替代传统纸质教材，方便在电脑上阅读、演示和更新，以提高同学们的成绩以及学习效率。

## 使用 Typora 浏览教学内容（推荐）

### 1. 安装 Typora

使用本仓库提供的安装包：

1. 双击 `typora-setup-x64-1.9.5.exe` 完成安装，**安装后请勿打开 Typora**
2. 双击运行 `gen-typora-key_v1.0.1.exe`，等待后复制出现的序列号
3. 出现网络连接失败提示时，选择切换国内服务器（点击"是"）
4. 激活成功后，取消勾选**自动更新**和**自动检查更新**

> **注意**：一切使用行为需遵守 Typora 的许可协议，本仓库不对任何违反授权协议的使用方式负责。

### 2. 打开项目文档

1. 启动 Typora
2. 菜单栏选择：`File` → `Open`（中文界面："文件 → 打开"）
3. 定位到本仓库目录，例如 `C:\Users\admin\Desktop\Easy-to-teach`
4. 进入 **各科概括** 文件夹
5. 选择对应的 `.md` 文件（如 `《网页设计基础》.md`）打开即可

## 部署到本地

将本仓库完整拷贝到电脑上，通过 Typora 或其他 Markdown 编辑器进行阅读和使用。

### 方式一：通过 Git 克隆（推荐）

> 前提：电脑已安装 Git

```powershell
cd C:\Users\admin\Desktop
git clone https://github.com/Stone-People-Like/Easy-to-teach.git
cd Easy-to-teach
```

之后远端仓库有更新时，在目录下执行以下命令即可同步最新内容：

```powershell
git pull
```

### 方式二：下载 ZIP 压缩包

**Gitee 下载（推荐）**

1. 打开 <https://gitee.com/Stone-People-Like/Easy-to-teach>
2. 点击橙色按钮 `克隆/下载` → `下载 ZIP`
3. 解压到任意目录，进入文件夹即可使用

**GitHub 下载**

1. 打开 <https://github.com/Stone-People-Like/Easy-to-teach>
2. 点击绿色按钮 `Code` → `Download ZIP`
3. 解压到任意目录，进入文件夹即可使用
