##  使用 Typora 浏览教学内容（推荐）

<details open>
<summary><b> 1. 安装 Typora</b></summary>
<br>

1. 双击 `typora-setup-x64-1.9.5.exe` 完成安装，**安装后请勿打开 Typora**
2. 双击运行 `gen-typora-key_v1.0.1.exe`，等待后复制出现的序列号
3. 出现网络连接失败提示时，选择**切换国内服务器**（点击「是」）
4. 激活成功后，取消勾选 **自动更新** 和 **自动检查更新**

>   **注意**：一切使用行为需遵守 Typora 许可协议，本仓库不对任何违反授权协议的使用方式负责。

</details>

<details open>
<summary><b> 2. 打开项目文档</b></summary>
<br>

1. 启动 Typora
2. 菜单栏：`File` → `Open`（中文：「文件 → 打开」）
3. 定位到仓库目录，如 `C:\Users\admin\Desktop\Easy-to-teach`
4. 进入 **各科概括** 文件夹
5. 选择 `.md` 文件打开即可

</details>

##  部署到本地

将本仓库完整拷贝到电脑上，通过 Typora 或其他 Markdown 编辑器阅读使用。

<details>
<summary><b> 方式一：通过 Git 克隆（推荐）</b></summary>
<br>

> ️ 前提：电脑已安装 Git

```powershell
# 克隆到桌面
cd C:\Users\admin\Desktop
git clone https://github.com/Stone-People-Like/Easy-to-teach.git
cd Easy-to-teach
```

后续同步最新内容：

```powershell
git pull
```

</details>

<details>
<summary><b> 方式二：下载 ZIP 压缩包</b></summary>
<br>

**Gitee（国内推荐）**

1. 打开 <https://gitee.com/Stone-People-Like/Easy-to-teach>
2. 点击   `克隆/下载` → `下载 ZIP`
3. 解压到任意目录即可使用

**GitHub**

1. 打开 <https://github.com/Stone-People-Like/Easy-to-teach>
2. 点击   `Code` → `Download ZIP`
3. 解压到任意目录即可使用

</details>
